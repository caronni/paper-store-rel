## Snapshot / run dir
- `holo.receiver.snapshot.read(path) -> tuple[fact, ...]` (flat, in fold order; FAMILIES = CaptureSurvey, Window, LatticeSeed, Placement, calibrate.CtxOutcome, PlaneField, PooledColorCtx, Certificate, EvidenceRevision). snapshot.py:52-61, :178-182. Peak RSS ~6.5 GB on the I snapshot (227 MB file).
- `data.Placement` (data.py:102-117): window_id=(capture_id, level_index, region_index, extent_cells), page, rot_k, page_origin_yx, native_affine (6 terms, PAGE cell (+0.5) → NATIVE px), pitch_px (NATIVE px per cell), route, local_cells_yx (N,2) window-local support, quality, refine_basis.
- `data.Certificate` (data.py:300-308): page, ty, tx, stream_id, user_bits uint8 (k−32−sites), source = `tiles/<stage>` (tiles.py:125-126; stages: scan, union, retry150, local150, planek150, swim150, uplift_*).
- `data.PlaneField` (data.py:227-257, RE-KEYED at the receiver's W2): page, plane(int), delta_dots_xy (ty,tx,2) in PAGE-axis printed dots, support (ty,tx), uncertainty_dots (ty,tx), n_observations, n_captures, ordinal (the page's evidence revision at solve time). Keyed (page, plane) and by nothing else — no capture, no level, no lane. `data.EvidenceRevision` (data.py:303-318): capture_id, page, revision — one per (capture, page), written at RunDone and folded back at the front of a resume. Both are in `snapshot.FAMILIES`; the pre-W2 ten-field per-lane node (capture_id, level_index, page, plane, n_certificates, n_sites, residual, median_delta_dots, delta_dots_xy, support) is what `snapshot.read` refuses on an archived corpus (README §2.1a). `data.PooledColorCtx` (data.py:278-288): offsets (8,3,9), applied (8,3), rung, n_lanes, n_rows.
- report.json keys: capture_facts[{capture, dpi, channels, levels_ppc, shape_yx, regions[{origin_yx, pitch_px, shape_cells, step_px}], placements}], captures[{ordinal, sha12}], pages, close{blocks[{have, needed, rank, solved}], k_total, metadata_rank, …}, plane_certs, replayed.
- events.jsonl: one JSON per line; `RunOpen` (format ref, pitch_in), `CaptureOpen`, `PoseCommitted`, `TileOutcome{page,ty,tx,stream_id,result,bp_iters}` (result == "certified" = the run's own mints; the I resume-3 run has 18 such events = 14 unique keys), `CloseCheck`.
- Rasters: `run_dir/<capture_id[:12]>/l{NN}-{r,g,b}.npy` (intake.plane_path :160; np.load mmap). Levels: `intake.build_levels(dpi, pitch_in, shape_px)` (:89-103) from `decimate.auto_ppc_levels(dpi, pitch_in)`; native = levels[-1]; each level has `.scale` (Fraction) and `.ppc`.
