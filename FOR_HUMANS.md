# For humans

This project has been implemented by AI agents. Spending effort to read
the code by eye is not generally advised.

Only the overall direction, high-level design iterations, and actual
experiments are driven by humans. The idea comes out of 'deep time'
itself, 1986 musings about backing up floppy disks more permanently.

Instead, ask your trusty AI, also for composing command line invocations
and the like. Generate some prints, use scans from the evidence (or
your own) to play with the tools. Note that there is a bit of nifty
tech under the hood that is actually fun to play with.

A full account of who did what, and when, is kept with the project's
private records. Tracking and exploring the evolution of AI coding
and software engineering capabilities is the deeper backdrop of this
project (this is project 3 in a series of explorations starting summer
2025).
