**RECEIVE-DESIGN requirement 5 ("no quadratic ledgers", docs/RECEIVE-DESIGN.md:78) is structurally delivered, and bookkeeping is not what dominates measured runs — but the receiver does carry several real, linearly-growing per-barrier overhead terms, one dead-code term worth seconds per barrier, and one latent correctness bug (not a cost) in the multi-capture K path.**

- **What dominates a run is the lane resolution ladder, not ledgers**: address stage 37–308 s/lane and payload stage 36–147 s/lane in the measured 2-capture / 8-barrier session. All session-layer bookkeeping combined (persist ~3 s/barrier at the 81 MB final state, dead index ~4–8 s/pass at the final 1784-block frontier) is roughly **2–8% of stage cost** — perceptible as a growing tail, not the headline.
- **The requirement-5 mechanisms genuinely work**: attempt/divergence ledgers fold to O(1) counters and never persist (`session_model.py:229-246`, `session.py:329-332`); evidence blocks of fully-certified tiles are pruned at every commit (`session.py:544-547`, load-time invariant `session.py:230-234`), so the retained population N is bounded by the *pending frontier* (≤ tiles × streams) and **shrinks as decode succeeds**; per-barrier delta validation is O(delta) against prebuilt index maps (`session.py:313-431`), never O(history).
- **What explains perceived slowdown over a run**: (a) later scale rungs/lanes are intrinsically more expensive — that is the ladder, not growth; (b) a genuinely *growing* per-barrier overhead tail of shape **O(B·(N·V + S))** — full-frontier walks with a Python-per-observation constant (two of them dead work) plus full-state re-encode/re-compress/re-read per persist — where **O(B·(delta + N log N))** was achievable; (c) with `--diag`, frame cost grows with accumulated display state (all-pages render + global word-dict scans + FreeType glyphs), charged honestly to observer_seconds but real wall time. Notation below: B barriers, N retained blocks (1784 final), C certificates (604), V obs/block (≤4096), S state bytes (81 MB), K captures, A attempts/delta, E events, P pages, R discovery branches.

**Critical correctness finding (verifier, empirically reproduced) — not a slowdown, a crash**: `production.py:820-825` passes the *merged frontier* as both `new_blocks` and `frontier_blocks` to `run_attempts`, so payload_engine Stage 1 (`payload_engine.py:151-158`) issues a SCAN for prior captures' blocks; `k_decode` binds `attempt.source_sha256 = context.capture.source_sha256` (`production.py:807-814`), and `session_validation.py:111-114` **refuses** any SCAN whose component `source_sha256` differs ("scan attempt does not use the current acquisition"). Net: a 2nd same-dpi capture with *any* retained uncertified prior block cannot commit its first payload barrier — the intended 3–4-scans/sheet workflow is broken in the K path. The color path is the correct reference: `production_color.py:288-294` passes `new_blocks` as current, frontier for unions. Fix = make K match color (touches the kiss ruling "resumes re-attempt uncertified streams" → needs an explicit design amendment, but it is now a bug fix, not an optimization). The original audit's "measured ~2× scan work" claim is **retracted as unexercised** — same-lane captures would have aborted. Test gap: `tests/holo/_qualify_production_roundtrip.py:590-657` certifies everything in capture 1; `tests/holo/_qualify_runtime_fixtures.py:345` hand-builds only current-component SCANs. ## 3. Latent-at-scale terms (fine today; hurt at 100+ barriers / many captures / discovery)

1. **Resume/invocation start-up repeats validation work.** Per invocation: `index_divergence_blocks` runs **3×** (SessionIndex validate=True at session.py:130, then `_validate_full→_rebuild_derived`:139, then the second index at runtime.py:557 — which is `validate=False` so it skips the structural walk but still pays merge + the dead index via `_rebuild_derived`); `merge_block_sets` 2×; keystream `validate_blocks_for_spec` (`_runtime_validation.py:159-178`, O(N·V) format_reference_values over every observed cell) **2×** (session.py:614 and runtime.py:556→_runtime_validation.py:250); `_validate_structural` 1× (verifier correction to the "3× same checks" framing). Capture-at-a-time workflows pay O(K·N·V) across a physical session. Fix: reuse the validated index from load; drop the duplicate index at :130 (immediately recomputed at :139).
2. **State-load per-block triple SHA + double body serialization** (verifier A3): loading N blocks pays sha256 three times each — `_decode_blob_items` digest check (state_codec.py:97-98), `EvidenceBlock.from_bytes` check (evidence_blocks.py:318-320), then `__post_init__` re-serializes the body via `_body_bytes` and hashes AGAIN (evidence_blocks.py:227-232) plus unpackbits/canonicality scans (:180-223). ~3× constant on the dominant resume-load cost, × K invocations. Fix: trusted from_bytes path skipping the constructor re-hash — exact (digest already verified).
3. **Discovery persist multiplication.** Every active-branch barrier persists the WHOLE DiscoveryState — all R branches — via `persist_child → persist_root` (discovery.py:754-763→410-432), plus a second full encode of the active branch (`authoritative_session_sha256(child)`, :763) and a full encode per (row, capture) `initial_digest` (:770); `load_discovery` validates every branch per invocation (discovery_state.py:198-202). O(B·R·S). Fix: derive the child digest from the branch sub-payload inside the root encode; cache per-branch payloads invalidated in `_replace_branch`.
4. **Full-frontier sort per UNION attempt in delta validation.** `sorted(frontier_blocks.items())` over the ENTIRE frontier for EACH union attempt (session_validation.py:136-143) ⇒ O(A_union·N log N)/barrier; plus `tuple(prior_attempts)` re-materialized per attempt (session.py:441-455, tuple copy at :448) and reversed-scan parent search (session_validation.py:124-130, 176-185) ⇒ O(A²). ~0.1–1 s/barrier at measured sizes, delta-local. Verifier A4 sharpens the constant: `validate_attempt` builds a `TileAttemptView` per attempt (:104) which sums 64×64 component tensors TWICE (evidence_blocks.py:674-676 then the `__post_init__` recheck :590-593), each `llr_cells()` materializing a dense (64,64) (:283-297) — O(A·components·4096) float work, growing with K via union views. Fix: group the frontier by (lane, address) once per delta; pass the list (no per-attempt copy); index parents by key; trusted-view constructor path. Identical accept/reject.
5. **Observer-forced full-state digest per barrier when persistence is off**: `elif events.enabled: digest = authoritative_sha256(candidate)` (runtime.py:343-344; also 441-442, 496-497, 649-651) — full encode+json+sha (~3 s at 81 MB) purely to stamp events. NOT exercised by the measured run (persist ran anyway, and the digest is reused via `_changed, digest = persist_state(...)`). Quadratic-in-B for in-memory runs with any observer attached. Fix: stamp last durable digest + barrier ordinal, or compute lazily on first snapshot opt-in.
6. **Barrier snapshot folds the FULL certificate set, not the delta** (viewer.py:554-567) although the snapshot already carries the delta (runtime.py:357-359, `_diagnostic_snapshots.py:92-104`). O(B·C_final); <5k iterations measured. Fix: fold `snapshot["delta"].certificates` incrementally; full walk only on resume/finalize.

## 4. Clean bill (checked, not growing)

- **Ledger folding is real**: attempts/divergences — the highest-cardinality per-tile records — fold to `SessionCounters` at commit and are never persisted (session_model.py:229-246; session.py:329-332, :556). Requirement 5's central claim, delivered.
- **Evidence pruning is genuinely anti-quadratic**: certified tiles' blocks dropped every commit (session.py:544-547) and pre-filtered per lane (production.py:777-780; vectorized `_prune_certified_k_owners` production.py:549-619); pending-block invariant enforced at load (session.py:230-234). N tracks pending work, shrinks with success. The expensive divergence kernel (`printed_cells_from_record` LDPC re-encode, records.py:363-415) runs only on this-barrier (certificate, block) pairs — prior-certified tiles have no retained blocks.
- **Per-barrier structural work is frontier-shaped, not history-shaped**: merge/retention/accept rebuilds are O(N log N) over the *current* frontier (session.py:432-435, 537-556, 492-507) — milliseconds at N=1784; `_validate_structural` is a single hash-set pass with no history replay (session.py:174-248); capture/level histories get O(1) prefix checks (session.py:288-307, 510-516).
- **Per-lane transients die at lane exit**: `build_evidence_context` views (evidence_context.py:66-90), lower-scale hints filtered to current capture + nearest prior lane before per-window work (evidence_context.py:41-63, portfolio hard-capped at 8, place.py:146-181), and all of place.py's E022 structures (ScoreMemo, observed_sites, deferred, scheduler queues — created inside `place_survey`, unreachable after AddressResult; place.py:561-575, placement/search.py:71-142). Within-lane superlinear loops exist (`pick_pending` O(P²·A) place.py:659-695; `chain_repass` deferred rescans :955-990 with outer loop 1013-1020; TileAttemptView double-sum evidence_blocks.py:590-593; cold-pick mask re-sum place.py:1024-1027 [A6]; `ordinary_certificates` linear scan production.py:834-836 [A5]; `_window_all_terminal` per-window re-sort `_payload_windows.py:196-203`, call sites :560/:707) — all invocation-local and dominated by hypothesis scoring; none accumulate across barriers.
- **Payload engine within a lane**: `blocks_by_address` built ONCE per lane (payload_engine.py:163), sorted address order, retry frontier from invocation-local records; CertificateStore is dict-keyed O(1) (records.py:296-355); `merge_block_sets` single-pass + one sort (evidence_blocks.py:482-493); freeze/collect paths linear in the current capture with exact generation-zero reuse (payload.py:130-344).
- **Event path honors req. 5**: `EventSink.emit` is O(details), no state serialization/hashing per event (observer.py:189-194, 291-326); snapshot factories are lazy pass-through reference dicts built only on viewer opt-in (diag/__init__.py:78-80; `_diagnostic_snapshots.py`); headless discipline genuine — high-rate adapters return immediately with no observer (observer.py:277-278, runtime_model.py:101-110), `begin_processor_timing` returns None without a clock read (observer.py:135-145); `_failures` bounded (observer disables on first fault, observer.py:315-323); jsonl append O(row), never rewrites (jsonl.py:65-98; minor fd-churn note A7: reopen per event, 3+ syscalls × 16k events); TimingObserver O(1) amortized, rows bounded by (capture, lane, stage) (diag/timing.py:45-66); viewer ingestion is delta-shaped and its accumulators bounded by page geometry (viewer.py:533-552, 418-445).
- **Full-state equality checks are not re-serializations** (runtime.py:373, 432, 652/661; session.py:567): dataclass eq over tuples resolves by element identity for shared prefixes — effectively O(K+N) pointer work. (Mechanism nit per verifier: tuple `==` walks min-length elements before length, so no length short-circuit — conclusion unchanged.)
- **Close accounting flat**: `close_progress` detaches counts only; metadata close O(C×24) GF(2); `certificate_frontier_sha256` O(C log C) only at close transitions (session.py:580-593); duplicate CloseProgress build per barrier under `--diag` (runtime.py:357-359, production.py:902) is microseconds.

**Bottom line**: no quadratic ledger exists; the frontier-bounded design works. The perceived slowdown = the resolution ladder's intrinsic per-lane cost plus a linearly-growing per-barrier tail dominated by three exact-preservingly removable terms (dead divergence index ~4–8 s, unconditional delta index, persist re-encode+re-read ~3 s + I/O double) and, under `--diag`, a frame cost that grows with display state. The one thing that must be fixed before the next multi-capture hardware session is the K-path frontier-as-current SCAN refusal (production.py:820-825) — it is a crash at the second same-dpi capture, and its fix requires an explicit RECEIVE-DESIGN amendment, not a silent change.
