## Live architecture/format overrides (current through 2026-07-26)

This entire file is a machine-extracted **historical evidence inventory**, not
the current receiver contract or qualification status. Entries are deliberately
not rewritten in place. Current `HOLO-DESIGN.md` and `RECEIVE-DESIGN.md` are
authoritative; verify every historical claim at its cited source before using
it as comparative evidence.

Current overrides which matter when reading the body:

- one certified bit per tile forms a counter-addressed LFSR GF(2) equation;
  the certificate retains its page/tile address and packed user bits while
  the full counter and certified metadata bit derive from the active format.
  Recovery needs rank 24 plus 48 distinct equations, and inconsistency is
  fatal—no `%24` residues or majority;
- Track-2 code and capture-wide normalization are quarantined, not a shared
  kernel or receiver dependency;
- current E022 route order is same-level chain, bounded lower hint, Stage-A
  word seed, then complete cold correlation;
- current Holo placement support is route-specific and applied separately to
  search and held-out validation parity:
  `max(30, ceil(log2(H)/(1-h2(p_max))) + margin)`. The complete default
  discovery envelope currently resolves to 57 per parity, while ordinary
  local, word-seeded verification, and bounded lower-hint routes remain at the
  retained operational 30 minimum.
  This is an identifiability rule, not a false-accept proof; exact semantics
  and page-domain authority are in `RECEIVE-DESIGN.md` §5.3;
- the body's historical instruction that E023 abort the whole session on any
  legal known-position BCH contradiction is replaced by Holo's attributable
  firewall. Final word voting retains the selected per-acquisition
  contributors; a legal mismatch quarantines every contributing placement
  before payload promotion, while refusal carries no negative authority.
  Unaffected placements continue and exact conflict/contributor records are
  persisted. This narrower policy is specified in `RECEIVE-DESIGN.md` §5.4;
- one original scanner acquisition is identified solely by its authenticated
  source SHA-256. There is no declared capture id or evidence-group axis.
  Every scale view is derived internally from that native raster; raw LLRs
  remain lane-local, and only distinct acquisition blocks may form a
  same-lane union. Byte-different re-encodings or transforms are not valid new
  evidence by input contract—their hashes cannot prove physical independence.
  An exact source with matching immutable facts resumes an incomplete prefix
  or is a no-op once complete; conflicting facts refuse;
- max-60 processing is followed in every lane by the selective
  evidence-addressed `retry150` stage. There is no retry option or persisted
  retry policy, but the distinct attempt stage/profile remains ledgered for
  cost, audit, and idempotence;
- production decode currently selects the exact unchanged historical E022
  stand-in row (alpha `1e-3`, assumed BER `0.08`, historical weighted gate,
  zero support margin, unchanged word policy/identifiers). Implicit/explicit
  selection has one semantic ID; `provisional` pipeline/result status is
  non-semantic and must be explicitly declared. Every run warns before
  state/raster mutation, the CLI always warns, and diagnostics initialize
  lazily, receive `receiver.provisional`, and retain it in the final report.
  Diagnostics are invocation-local operational output: no manifest, receipt,
  epoch, frame history, resume reconciliation, or implicit server. Observer
  failure remains downstream of reception. Physical/null/BER/support freeze
  and the post-hoist 312-page yield/wall/RSS run remain open;
- obsolete tests for the retired Track-2 namespace and discarded receiver
  APIs are removed; current tests invoke source-local Track-3 qualifications;
- Stage A accepts BCH within t=13 plus five-zero-pad/legal-page checks and then
  the ordinary disjoint pilot gate; it has no extra d>=27 or neighbor-arithmetic
  admission;
- lower-scale retention is eight hints total (normally six accepted plus up to
  two runners), not eight plus a reserve;
- retained local windows are 200 cells with 40-cell overlap; they were not
  tile-aligned for format-v1 convenience;
- E023b calibration uses predictable word/filler labels. Certified payload
  labels belong to E023c refinement/divergence, not generation-zero detector
  refitting;
- state binds a semantic component policy id and exact page hypotheses as
  separate axes, plus authenticated source SHAs, but no source-code/module
  fingerprint. The complete plan, source facts, causal artifact prefixes, and
  close are retained; stage disposition, level ordinal/lane/scale/source
  copies, and level/capture/session status derive from them. Discovery candidates,
  c-based exclusion, completion, selection, and status derive from branches
  and minimal survey decisions. Stage counts, detector labels, and retry
  summaries are operational event details rather than a persisted checkpoint
  ledger. Runtime owns state and successful barrier counts; a complete
  scheduler returns no value. Current Holo persists this compact causal
  frontier, not E024's historical raw-mean/non-owner replay substrate;
  and
- implemented detection is per-window `pava-v1` with production-default
  per-region `ctx-pava-v1` held-out adoption. Its physical performance remains
  unqualified.

Old port prescriptions—especially correlation-primary routing, tile-aligned
windows, open detector selection, implementation fingerprints, and Track-2
reuse—are inputs to the design history, not current instructions.

### port_notes (15)

### contracts (22)
- BOUNDARY: E024 is strictly LDPC-and-below — no fountain/RaptorQ rank accounting, no volume-recoverability decision, no session-completion condition; feedback fixed point is an algorithmic idempotence rule only, and a later independent scan or different registered arm can reopen the receiver (README intro + §4.10).
- E024.0 is a state-only post-pass over an immutable, externally referenced E023b artifact; it never alters E021/E022/E023b numerical behavior; prefix-safe new-scan ingestion was deliberately deferred as a later composition-root decision (README §13.7, memory Boundary).
- CERTIFIED-ONLY FIREWALL: only syndrome+CRC-certified payload bits may become labels; uncertified hard decisions, BP marginals, and decoder extrinsic LLRs never cross the feedback boundary (README §3.1).
- Authoritative certified value = (tile address, LDPC rate, certified user payload bits); the label export path regenerates the full LDPC codeword, handles shortened/off-page slots through the format mapping, maps codeword slots to page payload indices, and XORs with the page keystream to recover physical printed ink values; labels are never persisted as fabricated raw observations or infinite LLRs, and each exported label retains its source certificate ID (README §3.1, §4.2).
- SUPERSEDE, NEVER SUM: a revised sample from the same physical capture is an alternative interpretation, not new evidence. Independent evidence unit key = (capture_id, page, payload_index); at most one baseline-or-revision LLR per key; only independent capture IDs may sum. Rule explicitly covers: recalibrating the same raw means, re-sampling after a pose change, overlapping windows from one scan, and native/decimated views of one physical capture (README §3.2).
- MONOTONE CERTIFICATES: certified tiles are terminal — bits never change, never demoted, routine decoding never spends another attempt on them, and a conflicting certificate for the same tile is fatal; a generation may only add certificates or leave the set unchanged (README §3.3).
- EXISTING GATES REMAIN IN CHARGE: feedback proposes better evidence but may not weaken placement admission, bounded-LLR rules, LDPC syndrome checks, or CRC; a rejected feedback candidate contributes exactly (byte-identically) its parent evidence (README §3.4, hard gate 6).
- GENERATION BARRIER: certificates produced during a generation cannot train another revision until the next generation — makes the result independent of tile/region processing order and prevents same-round self-support; all revisions/attempts are built on a private fork and new certificates are committed together only after every target is evaluated (README §1, §4.10).
- TARGET-SAFE EVIDENCE: every revision carries the exact transitive set of certificates used for calibration, pose refinement, gating, owner selection, and search/pending-mask pruning; a revision is illegal for target T if its dependency closure contains T; the resolver walks revision predecessors to the newest legal value, else that capture/cell is an erasure. This closes the indirect cycle A-labels-revision-certifies-B, B-labels-revision-tries-to-certify-A (README §4.4).
- NATIVE/DECIMATED SHARED TRUTH: correlated views' LLRs must never be summed as independent scans, but certificates are page-global printed truth — a certificate recovered on one footing may legally supervise the other footing's pixels. Target leave-out still applies: a union-seeded certificate for T becomes generation-zero truth (not counted as feedback recovery) and no revision depending on T may causally support re-certifying T (README §7).
- BP SCHEDULE CONTRACT: changed targets receive per-scan max-60 BP, then union max-60, then union max-150 only after an actual max-60 failure; with one contributing capture the union max-60 deduplicates to the identical scan max-60 record, which is the legal parent of the max-150 retry; identical numeric evidence + decoder profile gets at most one CRC-bearing attempt regardless of lineage (memory Hard laws, README §4.9, §13.5).
- OWNER COMPETITION: feedback candidates compete on the same fixed E023b pilot-validation sites, on the same unweighted log-loss scale as generation zero — one comparable ranking scale across baseline and revisions; after every accepted recalibration deterministic owner selection re-runs over all retained window evidence for that scan (a former non-owner may become owner without a second physical vote) (README §4.5, §13.4).
- DISCRETE PLACEMENT IMMUTABLE: E022's admitted page, orientation, integer origin, BCH result, placement mismatch, rival/gap result, and audited core are frozen; E024 pose candidates only re-check E022's hard pilot-mismatch rule on the authoritative-core pilot population against the immutable generation-zero threshold, stay inside the registered refinement box, and must improve dense held-out log loss on independent spatial blocks (README §4.6, memory Numerical choices).
- Pilot labels remain legal and independent of payload certification; validation confidence units are spatial blocks/tiles, never individual neighboring cells (thousands of correlated cells in one tile are not thousands of independent trials) (README §4.2, §4.5).
- Only a pose-changing arm re-samples the TIFF (after rechecking SHA, size, shape, dtype); the pose-only refine arm replays the generation-zero detector score/logit path exactly; combined may fall back to the exact frozen detector when the learned detector refuses an admitted pose (README §4.6, §4.7).
- CELL-GRANULAR SUPERSESSION: a new window may improve only part of an old observation; the unrevised remainder must survive byte-for-byte; untouched generation-0 cells preserved exactly (README §4.8).
- CERTIFICATE IDENTITY: H(format, seed, page, tile, rate, packed certified user bits); origin attempt is provenance, not identity; same tile+bits = same certificate; different bits or rate for one tile = fatal (README §5.3).
- ATTEMPT IDENTITY: target + decoder profile + numeric evidence digest (per-capture component digests included), not generation number (README §5.6).
- DIAGNOSTICS OBSERVER-ONLY: diagnostic failures cannot affect a feedback transaction; diag on/off must produce identical authoritative state (hard gate 11); in-flight frames render the provisional active-revision map actually used by that decode, never substituting the previous committed head (README §8).
- FAIL-CLOSED LIST (README §6): load/commit fails if gen-0 blob/hash/digest changes; union root fails type-strict replay through the fingerprinted merger; an ID or dependency closure does not recompute; a child uses same-generation or future labels; a certifying closure contains its target; conflicting certified bits; a certified tile is demoted or re-decoded; a patch crosses capture/page boundaries or names the wrong predecessor; two active values exist for one capture/page/cell; two views of one capture enter the independent-capture sum; a refused revision becomes active; stored pose/detector/emission algebraic replay differs (incl. the exact retained gen-0 score/logit path); candidate discovery, refused decisions, decode scheduling, or the fixed-point reason differ under sequential replay; TIFF identity/metadata changes on pose reread; source pixels fail SHA; identical evidence/profile spends a second CRC attempt; a below-floor decision is counted as CRC exposure; diagnostic activity changes state.
- Profile + numerical configuration are part of the state fingerprint — never reuse one E024 state with another profile; the CLI's omitted-profile default stays 'combined' purely for fingerprint stability while the measured recommendation is explicit --profile refine (HOWTO).
- Certificate-union bundle is certificate truth only — not extra pixel evidence; it does not permit summing native and decimated rasterizations of one capture; --certificate-union is accepted only with --fresh (HOWTO).

- POSE PROPAGATION (README §4.1): an accepted window proposes the FULL affine pose (never angle-only — that discards scale/shear/phase; propagating acceptance would be a correctness bug) to unplaced windows of its region as a SEARCH PRIOR ONLY: the neighbor fits its OWN spectral pose and phase first; a bounded local placement check (a few cells around the prediction) must pass on search parity and be confirmed on validation parity; disagreement beyond the consistency bound re-anchors through the full-page search and, if the independent placement wins elsewhere, opens a NEW pose component (touching scraps, physical breaks); failures leave the window unresolved and never veto other windows. ### contracts (26)
- BOUNDARY: E023b ends at honest per-LDPC-tile outcomes (syndrome+CRC-certified tiles) plus the evidence needed to explain or revisit them. It performs NO fountain/RaptorQ accounting, NO volume-recoverability decision, NO session stop condition, NO E024 feedback (README §0, §8; memory). score_e023b.py is an optional read-only evaluator ABOVE that boundary; it may compute fountain rank but never mutates receiver state (README §0, SCORE.md).
- TRANSACTION: one TIFF = one atomic transaction: validate+hash TIFF -> ONE whole-scan E021 survey (platen.detect_payload_regions exactly once, retain complete PayloadSurvey with losslessly packed masks) -> ONE scan-wide E022 pilotsearch.search_survey call with per-region on_region diagnostic callbacks -> explicit pilot_final barrier frame -> payload work plan + per-region/window evidence -> freeze one owner per scan/page/payload-cell -> per-scan LDPC (Stage 1) -> changed cross-scan union (Stage 2) -> divergence -> atomic commit (README §2 diagram).
- BATCHING EQUIVALENCE: a single invocation with TIFFs A B C must equal three ordered invocations with A, then B, then C in authoritative state, tile outcomes, attempts, and bits (README §1; qualification gate 4). Stage 2 runs after EVERY completed scan even in one multi-TIFF command, making CLI batching irrelevant; each TIFF commits independently (README §3.5, §3.6). Acquisition order is part of the append-only session history; arbitrary permutation invariance is NOT claimed (README §3.5).
- PHYSICAL-EVIDENCE INVARIANT: --capture-groups (required for ingestion) names one physical scanner capture per TIFF. Independent captures get distinct ids and may contribute summed calibrated LLRs; TIFFs derived from the same capture must repeat the id and E023b REFUSES to sum them twice. Explicit declaration is intentional: file hashes cannot prove physical independence for crops, resamples, or metadata-only rewrites (README §1; HOWTO 'Important state rules'; memory).
- ONE STATE = ONE DPI/FOOTING. The session envelope freezes: format id, seed, page geometry, pilot layout, legal page set; input DPI/footing and independent-evidence policy; LDPC rate and detector profile; E021, E022, payload-sampler, and state-schema versions/configuration hashes. Envelope mismatch refuses and asks for another state (README §1, §5.1). Per-page rate should be represented by page even when all pages share one registry rate (README §5.1).
- DUPLICATE-INPUT IDENTITY: a TIFF whose SHA-256 is already committed is a true authoritative no-op — no new scan id, no decode attempt, no rewritten attempt ledger, no tile-state change; the 650,054,933-byte state's SHA-256 and mtime were preserved exactly on refeed (README §1, §7.1; gate 5).
- COMPOSITION NOT FORKING: E021 and E022 remain independently runnable tools; E023b is the composition root and does not absorb or fork their algorithms. Calling E022 with a fresh SearchResult per scrap would CHANGE the algorithm: it would lose same-scan pilot completion, change which placements are marked redundant, and discard shared pending masks (README §1, §2.2).
- PILOT-FINAL BARRIER: the last E022 region callback is NOT the final result — search_survey calls decode_known_tiles only after the region loop. E023b must publish a distinct pilot_final frame after the return: (1) retain the complete scan-local SearchResult, (2) combine committed+current pilot observations by absolute address, (3) run the same final known-position BCH evaluation as E022, (4) fail closed if the qualified zero-contradiction invariant is violated, (5) render panes A/B/C exactly as final E022 would. Panes B/C stay on that final state while pane D advances (README §2.3).
- SCAN-FINAL LDPC BARRIER: payload calibration is per-window local (no whole-scan radiometric field needed), but LDPC waits for all scraps in the TIFF because (a) different scraps can provide complementary cells to the same LDPC tile, (b) the one-owner rule cannot finalize until every covering window is known, (c) region-wise decoding would create avoidable attempts, spend extra CRC false-accept budget, and make outcomes region-order dependent. A performance pipeline may sample completed regions during E022 (accepted poses don't change) but must preserve scan-final ownership + LDPC barrier byte-for-byte (README §2.4).

PlacedWindow.page_cells_yx is the authoritative audited core; E023b invents no new erosion policy. Per core cell: map through compose.payload_index_map(), discard pilot/off-page cells, map payload index to (page,tile_y,tile_x), record coverage + contributing region/window. 'Potential tile' controls decode work but must NOT prune the cells used for a window's median/spread or pilot calibration — such pruning silently changes the qualified detector (README §3.1).
- WINDOW EVIDENCE (qualified pava-v1 path, preserved exactly): (1) invert stored rotation/origin to local authoritative-core cells; (2) sample each core cell through the stored affine pose from the ORIGINAL TIFF using the aperture-0.7-cell uniform prefilter and order-1 read (one extent-bounded prefilter per E021 region); (3) ink-positive score = (median(cell_means) - cell_mean) / mean_absolute_deviation; (4) regenerate pilot labels from the format seed; (5) deterministic SEARCH-parity labels for PAVA, disjoint VALIDATION parity for held-out log-loss; (6) calibrate-or-refuse when either class or the held-out set is too small; (7) bounded PAVA LLRs applied to every core cell; (8) retain payload cells and descramble into payload-bit LLR sign (README §3.2).
- WindowEvidence stores: stable placement id, page/payload indexes, raw cell means, derived scores, calibration nodes, emitted LLRs, label counts, held-out score, refusal reason, source-region/pose lineage. NON-OWNER evidence is retained (E023 discarded too much for E024). Transient pane-D states never mutate a durable TileRecord (README §3.2).
- ONE-OWNER FREEZE (per scan): only after ALL window evidence exists, choose exactly one owner per (page, payload_index): lowest held-out log-loss wins; stable full-placement id is the deterministic tie-break; a refused window emits no vote; overlapping windows from the same physical TIFF never become independent votes. Result = immutable ScanEmission partitionable by LDPC tile; owner identifier must remain resolvable to its WindowEvidence, never a fragile list ordinal (README §3.3).
- STAGE 1 (per-scan decode, deterministic page/tile order, touched still-uncertified tiles only): gather 4096 logical LLR slots (missing = exact erasures); apply ldpc.tile_shorten_mask(); zero user capacity = degenerate; k_eff = k_bits - n_shortened; n_informative = count(nonzero LLR on non-shortened slots); if n_informative < k_eff record below_attempt_floor WITHOUT invoking BP and WITHOUT spending CRC exposure; otherwise run qualified decoder; accept ONLY its syndrome+CRC verdict; retain certified user bits, rate, iterations, exact evidence provenance. Durable tile states: unobserved | below_attempt_floor | attempted_failed | certified | degenerate (README §3.4).
- CERTIFICATION IS TERMINAL for the production scheduler; later independent evidence is compared cheaply against the deterministic re-encoding and recorded as DIVERGENCE (append, don't recompute history). E023b does not claim to detect a second conflicting certificate while skipping certified tiles; a separate qualification/corroboration mode may deliberately re-decode, but not routinely (README §3.4, §3.6). Deliberate path dependence: an earlier valid certificate is retained even if the final aggregate would not decode from scratch (MULTIVIEW §4.4).
- STAGE 2 (changed cross-scan union): for still-uncertified tiles affected by the new scan, sum AT MOST ONE owned LLR per independent physical scan per payload cell; never sum two derived versions of one capture. Attempt identity = (page/tile, stage, decoder profile, evidence digest); union digest derived from session-ordered constituent per-scan tile-evidence digests. Consequences: one-scan union identical to Stage 1 is skipped; an unchanged resume cannot repeat a failed attempt; a failed tile retries only on genuinely new evidence; changing decoder policy deliberately creates a new attempt identity (README §3.5).
- DIAGNOSTICS OBSERVER-ONLY: --diag on/off must produce byte-identical authoritative state; diagnostic failure disables diagnostics, never aborts. Four panes: A scan space, B page placement (prior vs current provenance), C pilot state (final known-position BCH), D payload/LDPC (committed five-state fill + separate transient overlay). Provisional coverage must NOT be painted as a provisional CRC verdict. Milestones: scan_open, e021_complete, e022_region_complete xN, pilot_final, payload_plan, payload_region_emitted xN, scan_owner_frozen, ldpc_batch xM, union_complete, scan_committed. Multi-page: B/C/D page-filtered, no renderer may hardcode page 0 or overlay placements from different pages. Frame numbering monotonic across invocations but NOT authoritative state (README §4). Status metadata contains NO fountain/volume-completion fields.
- DETECTOR-PROFILE FREEZE: the profile (pava-v1 default | ctx-pava-v1) is frozen in the state envelope at creation; a state cannot append scans under a different profile; the profile is also recorded in each scan record. A context-rejected region deliberately retains exact pava-v1 rows with the decision in the ContextFit sidecar. The ordinary loader fails closed across implementation or schema changes, including the entry-point harness (ARMS §1).
- BP RETRY CONTRACT: explicit state-only action (no TIFFs/--capture-groups/--fresh), its own attempt identity/profile/CRC exposure, visible in the ledger. Eligibility: tile state attempted_failed AND its most recent transaction-final baseline EVALUATION (whether or not it invoked the decoder — a newer below-floor evaluation blocks backward search to an older failure) also attempted_failed AND no max-150 attempt with that evidence digest already ledgered. Retry reconstructs exactly the contributing scan/union named by that attempt — no post-hoc scan subset; with >=2 contributing scans the transaction-final row is the full-prefix union. Below-floor and degenerate tiles never retried; outcome only failed or ordinary syndrome+CRC certificate; conflicting certifications fatal; rerun without new evidence = authoritative byte-for-byte no-op. State validation derives the frontier from frozen scan records and rejects reordered/omitted rows pre-retry (ARMS §2.2-2.3).
- ctx-pava-v1 CONTRACT: run pava-v1 first unchanged; any window refused by baseline calibrate-or-refuse REMAINS refused (context never creates an uncalibrated emission mode). Context valid only when all 8 immediate page-grid neighbors (by absolute page coordinate) occur in the same window core, else the cell keeps L0. Neighbor field computed ONCE from provisional bits (L0>0); corrected decisions never fed back into the count. Per (scan,region): pool SEARCH-parity pilot samples from non-refused windows; parity keeps every duplicate observation of one physical pilot on one side of the split (no label leakage); all observations of one physical pilot total weight one (1/multiplicity), split fractionally across bins; raw counts persisted separately. Fit tau[0..8] additive logit offsets, L = L0 + tau[n]; adopt only if pooled VALIDATION log loss STRICTLY lower, else return byte-identical baseline region; when adopted, corrected LLRs clipped to [-12,12] and each window's held-out log loss recomputed from corrected values remains the ownership score (ARMS §3).
- HONESTY BOUNDARY: only known pilot labels train or gate forward arms; payload ground truth is qualification-only; CRC-certified payload labels are reserved for an explicitly versioned feedback generation (E024) with leave-target-out dependencies — never silently consumed (ARMS §3.5).
- MULTIVIEW MERGE CONTRACT: native and decimated rasterizations of one capture are correlated decode hypotheses, not independent scans and not one prematurely fused likelihood. Honest combination = two ordinary states with IDENTICAL ORDERED physical capture ids, then merge_e023b.py unions ONLY conflict-checked syndrome+CRC certificates; two certificates for one tile with different bits = fatal integrity error; it never combines scan LLRs; every decoder/CRC exposure still counted. The merger validates current states, capture alignment, tile capacity, certificate bits, exact certifying-attempt provenance; streams one state at a time (hash/validate/reduce to compact packed certificates before loading the next). Output is a TERMINAL bundle, not a resumable state — never pass back through --state; regenerate when either source changes; retain both source states for E024 (MULTIVIEW §3; HOWTO 'Combine'; README §7.3).
- SCORER CONTRACT (SCORE.md): read-only handoff from one E023b state pickle to an emitted-sheet manifest. Validates the complete format identity: format id, fixed seed, cell size, page geometry, legal pages, LDPC rate, fountain version, data length, symbol geometry, expected payload SHA-256. Reports tile-state counts + CRC-attempt cost, certified tiles, certified INTERIOR fountain symbols (excluding inert edge certificates), actual fountain rank / required source rank / shortfall, recovered length+SHA when solved. Under-ranked = valid OPEN, exit 0; --require-recovered makes open exit 4; --recovered-out writes atomically only after length+SHA verification. Never score against a same-profile manifest for another payload — the public format key is reused; manifest data length + SHA bind the instance. Does not consume the multiview-union JSON.
- E024 SUBSTRATE RULES (recorded in E023b, enforced by E024): feedback-derived evidence records the certificate ids used as labels; multiple derivations of one physical sample share a capture id and SUPERSEDE rather than sum; dependency records support leave-target-out so a tile cannot certify itself through labels descended from its own certificate. Certified user bits + LDPC rate remain the logical source of truth; the codeword and physical payload labels regenerate deterministically and are NEVER written back as fabricated raw LLRs (README §5.4).

### gate_constants (16)
- Attempt floor: n_informative >= k_eff, k_eff = k_bits - n_shortened, computed PRE-decode from mask + nonzero LLRs — inherited from qualified E023 (conservative, not a strict bound: CRC leaves k_eff-32 dof); below-floor spends no BP and no CRC exposure (README §3.4).
- Baseline decoder: normalized min-sum, alpha = 0.8, max 60 iterations; after syndrome failure one fresh exact sum-product pass at max 60. Ledger profile '<rate>/decode_tile-max60-alpha0.8'. Inherited byte-identical from qualified E023/E023b.0 (ARMS §2.1).
- BP retry decoder: same decode_tile with max_iters = 150, alpha = 0.8 — worst case 150 min-sum PLUS 150 sum-product, not 150 total. Profile '<rate>/decode_tile-max150-alpha0.8', stage 'retry150'. Preregistered in ARMS before qualification (ARMS §2.3).
- Context-fit eligibility: >= 80 context-valid SEARCH samples including >= 20 examples of EACH central value, AND >= 40 context-valid VALIDATION samples including >= 10 of each value. Preregistered (ARMS §3.3).
- tau constraints: tau[0] >= tau[1] >= ... >= tau[8] (monotone: inkier neighborhood may only push the central cell toward white relative to the marginal detector — physical direction) and -4 <= tau[n] <= 4. Fixed symmetric prior: one synthetic label-0 + one synthetic label-1 per bin at baseline logit zero (shrinks sparse bins, prevents infinite offsets). Deterministic generalized PAVA blocks; block optimum = unique clipped root where predicted ones equal observed ones, fixed-tolerance bisection. Preregistered (ARMS §3.3).
- Context adoption gate: pooled VALIDATION log loss of L0+tau[n] STRICTLY lower than baseline L0, per (scan,region); otherwise byte-identical baseline region. Preregistered, held-out, pilot-only (ARMS §3.4).
- Corrected physical-value LLR clip: [-12, 12] when a region model is adopted; cells without a complete 8-neighborhood retain L0. Preregistered (ARMS §3.4).
- Context validity: all 8 immediate page-grid neighbors must occur in the same window core (support condition for the correction; measured complete-neighborhood coverage 97.16% decimated / 97.23% native) (ARMS §3.2, §5).
- Sampling constants: aperture-0.7-cell uniform prefilter + order-1 subpixel read through stored affine pose — inherited from the measured decimate-first radiometrics (README §3.2).
- Detector score: (median(cell_means) - cell_mean) / mean_absolute_deviation, ink-positive — inherited from qualified E023 single-arm detector (README §3.2; ARMS §3.1).
- Train/validation parity split: the frozen '(131*y + 17*x) & 1' search/validation site split — inherited from E022; the 2026-07-16 fix constructs the IDENTICAL split only over the page/fragment overlap (semantic no-op, 8.8x speedup) (README §7.1).
- CRC false-accept accounting: attempts x 2^-32 ledger. Measured bounds: 2.5053e-7 (decimated) and 2.5565e-7 (native) at qualification; multiview union conservative bound 2226/2^32 = 5.1828e-7 counting ALL calls of both branches without assuming independence (README §7.1; MULTIVIEW §1).
- Ownership rule: lowest held-out log-loss wins; deterministic tie-break by stable full-placement id — inherited from E023 (log-loss chosen because wrong-rate is tie-heavy) (README §3.3).
- Diag frame throttle: render the first attempt in a stage, every 40th attempt, and the final union_complete (instead of 700-900 frames) — implementation choice, observer-only (README §4).
- E022 local anchor attempt tests up to 49 neighboring origins plus validation (context for why per-probe full-page parity construction was pathological) (README §7.1).
- Experimental overrides --rate and --no-bch-first exist but must be omitted for the qualified setup (HOWTO 'Important state rules').

### dead_alleys (18)
- Summing native + decimated views as independent evidence (twelve scans, or distinct capture ids for derived rasters of one capture): overstates evidence; the ordinary session refuses it by envelope (one DPI frozen; repeated capture_id cannot re-sum). Never re-port a path that allows it (MULTIVIEW §3; HOWTO).
- Cell-level LLR fusion across correlated views: all three tested rules (equal convex mean, lower-held-out-loss view, prefer-decimated-fill-native) produced strict SUBSETS of the certificate union (best 763 < 769) — more coupled, averages away view-specific hypotheses, zero new certificates. Not promoted; certificate-boundary union is the honest combiner (MULTIVIEW §5).
- Fresh E022 call per scrap (per-region SearchResult): changes the algorithm — loses same-scan pilot completion, changes redundant marking, discards shared pending masks. One scan-wide search_survey only (README §2.2).
- Region-wise LDPC decoding before the scan-final barrier: creates avoidable attempts, spends extra CRC false-accept budget, makes outcomes region-order dependent (README §2.4).
- Copying E023's monolithic emit_scan() as the orchestration interface — explicitly rejected; split into plan / immutable observation / scan-local reduction / decode scheduling (README §3).
- Porting the old 16-context GMM/ICM detector as the context arm — deliberately NOT done; ctx-pava-v1 is a one-shot, low-dimensional, pilot-only ordered-logit correction instead (ARMS §3).
- Retry-after-every-scan-prefix as default BP schedule: 140-157 extra CRC calls and ~44k-50k extra iterations per branch for one PAVA-only tile and ZERO context-arm gain; final-only remains the recommended schedule for the best arm (MULTIVIEW §2).
- _score_known() constructing the full 3300x2220-cell page parity split for every local origin probe (up to 49 per anchor, growing anchor lists): pathological on HP-C2; compute the identical frozen split only on the page/fragment overlap (0.837 s -> 0.095 s, 8.8x, semantic no-op) — build it the fast way from day one (README §7.1; memory).
- Pre-E021.6 full-area fine segmentation replacing coarse support: turned 4px/cell tensor silence into physical holes plus a nested region and 449 fragmented placements; coarse-authoritative boundary/gap refinement fixed it (294 placements, certs 741->1392) (memory; README §7.1).
- BER-only promotion of a detector arm: recorded but does NOT automatically make it the production default — judged on certificate yield AND held-out calibration AND the baseline-certificate trade (ARMS §4, §5).
- Trusting file hashes to prove physical independence of captures (crops/resamples/metadata rewrites defeat it) — explicit --capture-groups declaration is mandatory (README §1).
- Passing the terminal multiview certificate-union JSON back through --state (it is not a resumable receiver state) or scoring it with score_e023b.py (scorer takes one authoritative .pkl only) (HOWTO; SCORE.md).
- Scoring a state against a same-profile manifest for a DIFFERENT payload instance: the public format key is intentionally reused; only manifest data length + SHA-256 bind the instance (SCORE.md).
- Owner identifier as a fragile list ordinal — must be resolvable to its WindowEvidence (README §3.3).
- Opening the large search space (many resize kernels, weights, BP settings, placement variants) all at once — rejected; keep a small bounded hypothesis set exactly where the winner-take-all decision is unstable and let LDPC+CRC adjudicate (MULTIVIEW §6).
- Pretending the E023b state contains E024's revision graph — v2 schema deliberately does not; the migration must add explicit generation ids/parents/active revisions/certificate dependencies while preserving generation 0 byte-for-byte (README §5.4).
- Correctness-first quadratic revalidation of all committed scan derivations on load/apply/save: measured acceptable at six scans but a known scaling dead end — replace with pinned per-record canonical hashes + authenticated aggregate + periodic full audit before large sessions (README §7.1).
- 'One-scan union identical to Stage 1' as a separate attempt — skipped by design; do not re-spend evidence identities (README §3.5).

### port_notes (14)
- SELF-ADDRESSING CHANGES THE PILOT LAYER, NOT THE PAYLOAD LAYER: in colocated v1 every 64x64 tile carries its own 100-site BCH word, so E022's global-pilot-lattice machinery (scan-wide pending-site accounting, lattice anchor/chain, word-vs-correlation routing) shrinks to per-tile word detection + local pose; but the E023b payload pipeline (work plan -> immutable WindowEvidence -> one-owner freeze -> Stage1/Stage2 -> divergence) is format-independent and ports as-is. - CALIBRATION LABELS: the SEARCH/VALIDATION parity split ((131*y+17*x)&1) over pilot sites and the calibrate-or-refuse rule are load-bearing; v1 must define an equivalent deterministic per-site split over its colocated 100 sites/tile. ### state_model_facts (14)
- --state is an authoritative atomic checkpoint, not a result cache: writes serialize a VALIDATED snapshot to a same-directory temp file, flush+fsync, atomic replace; loads authenticate the envelope, semantic state digest, per-lane digests, and cross-object invariants; a bad schema/envelope/digest/invariant is rejected (fails closed).
- State envelope freezes: algorithm+schema id; format id, format seed, LDPC rate, selected pages, native DPI; exact ordered ScaleSpecs + resampler ids; detector profile + complete E022 search-configuration digest; run-policy digest (lower hints on/off, runner-up bound, forward refinement, BP-retry policy); optional manifest hash; implementation hashes for E023c, feedback, fountain, scorer, and the TRANSITIVE E021/E022/E023b numerical closure. Changing numerical options requires a fresh state — no silent mixing of runs.
- Source records bind path, file hash/size, raster shape/dtype, native DPI, and physical capture id. A moved source may replace its path at resume ONLY after bytes AND metadata authenticate as the same source. Each materialized view is content-addressed by source hash + level; its hash/size stored with the completed level and lane scan. Derived-view identity mismatch is fatal.
- Semantic vs observer field split is explicit and load-bearing: algorithm-consumed nested state (including SearchResult.diagnostics['window_audit']) is SEMANTIC and inside the authoritative digest (changing it can change later search); rendered diagnostic frames and timings are explicitly non-semantic/excluded. This is what lets observer-only code changes be proven state-neutral.
- Validation replays structural invariants on every load: scale-plan strict order + native final level; unique source/capture identities; capture/level/checkpoint status consistency; lane identity, parent closure, lane semantic digest; attempt/certificate origin + evidence identity; dependency existence, acyclicity, earlier-barrier order; certificate-union conflict + frontier replay; latest pilot state from the latest committed barrier; explicit early-stop/skipped tails.
- Capture transaction lifecycle: pending / in_progress / exhausted / early_stopped; individual finer levels after verified recovery are explicitly skipped_volume_verified. Resume schedules persisted unfinished captures BEFORE any new capture; an exact already-exhausted capture is an exact no-op; a previously verified capture is a no-op unless --complete; in complete mode skipped levels become pending and reconstruct from the authenticated stored source path (or authenticated replacement). Completed lower levels and lanes are never replayed. One multi-scan invocation ≡ repeated one-capture invocations under the same envelope.
- Schema v1 is INTENTIONALLY incompatible with the factorial prototype (no compatibility contract). States made before the live-diagnostics revision cannot be resumed with it (fingerprints pinned) — start fresh, keep the old state/report as pinned historical evidence.
- Provisional work is never authoritative: a crash before the atomic level/capture commit (step 13) leaves the last valid barrier available for deterministic replay.
- The retained replay surface is deliberate: exact dependency sets, source/view identity, opaque per-scale E023b sessions (scan records, E021 survey, E022 result+audit, immutable window evidence, owners, decoder tile states, attempt ledger), accepted poses, and the bounded window_audit loser ledger — so a future feedback experiment can select and replay a dependency cone rather than rediscovering provenance. Level dependency set for refinement = conservative union of certificates whose printed labels contributed to an adopted refinement, interned and bound to resulting attempt/certificate provenance.
- Report JSON is rebuilt directly from committed state after commits; the final --out PNG is likewise rebuilt from committed state even on a no-op/resume invocation and even with live diagnostics disabled/failed (when the retained scan/view path is readable). The state + authoritative digest decide what was recovered — never a PNG or JSON observer artifact.
- Big states stay out of Git: the two-capture C2 authoritative pickle is 2.1 GB scratch; the compact report + frozen hashes (state file sha 21f599c4...583e, authoritative digest 76ebdb11...9c57, report identity set 64a0890d...c814, audited key set c3d03724...883a, audited bits dfb352ec...901f0b) retain reproducible identity. Qualified C3 state: file sha 02e32656...8faf, authoritative digest 46194a28...b541b.
- Cache discipline: --cache-dir (default '<state>-views') holds exact direct-from-native derived-view PNGs recorded by content identity; cached views are NOT authoritative evidence by themselves.
- --fresh resets receiver state but does NOT clear old diagnostic frames — qualification runs need a new empty diag directory.
- PORT CONFLICT to flag: E023c's fail-closed identity mechanism pins TRANSITIVE SOURCE-CODE fingerprints; holo v2's locked rule is NO source-code identity in state (artifact content hashes + schema versions only, HOLO-DESIGN). The port must keep the fail-closed envelope semantics (numerical-policy mismatch refuses resume) while re-basing identity on artifact hashes/schema versions — and keep the E023c lesson that the semantic/observer split plus exact-delta pinning is what made the 5ee753a observer-only revision auditable.

### port_notes (13)
- GRID UNIFICATION COLLAPSES A LEGACY DICHOTOMY: E023c's evidence layer was built for pilot tiles of 60x60 cells vs LDPC tiles of 64x64 cells on deliberately MISALIGNED grids, where a ~200x200-cell placement feeds several LDPC tiles and 'valid BCH address' ≠ 'payload tile solved' (FUTURE_WORK). Holo v1 colocates the 100-site BCH word, LDPC codeword, and metadata bit on ONE 64-grid per tile. Port consequences: (a) pilot-solved and payload-solved become per-tile-aligned but remain DISTINCT states — keep 'address known' ≠ 'payload certified'; (b) the pilot pending mask and payload NeedMap can share one tile index but must keep separate semantics; (c) DESIGN §10 reason 1 for not hard-cropping search ('pilot/pose need and payload need are different fields') weakens, but reasons 2 and 3 (windows overlap/solved tiles anchor neighbours; independent captures can improve failed tiles) survive unchanged — so the NO-HARD-CROP rule still holds in v1.
- SELF-ADDRESSING DENSIFIES THE BCH ROUTE: legacy E022's route ladder (same-level chain → bounded lower hints → BCH → full-page correlation → subdivision) had BCH words only at pilot-tile sites; in v1 EVERY 64-tile carries an address word, so BCH-first seeding becomes available everywhere. Measured guidance to carry over: full-page correlation earned 0 post-seed accepts (make it a component seeder only); nearest-earlier-anchor chaining reproduced 100% of successful chain placements; subdivision, not address search, is the correct response to locally weak pixels; retrying failed windows against new anchors recovers nothing (0/48, 0/64).
- KEYSTREAM SWAP IN THE REFINEMENT SEAM: certificate-labelled pose refinement regenerates exact printed labels 'from format seed, keystream, shortening mask, and certified user bits' (DESIGN §7). In holo v1 the keystream is AES-128-CTR as a pure function of address (SHA-256 KDF), not BLAKE2b→Philox; the regeneration path must call holo.core.keystream. The concept — certificates as exact printed-cell labels for bounded pose-only refinement with held-out log-loss + pilot non-regression adoption gates — ports intact and was frequently eligible (50/142, 43/142 adopted) though its isolated certificate gain is unmeasured (needs a --no-forward-refine arm).
- METADATA BIT AND CERTIFICATE IDENTITY: v1 tiles carry 1 LDPC user bit of metadata (M=[ver:1][K:18][rsv:5], counter mod 24, majority over certified copies — but per holo rules certified DISAGREEMENT is integrity-fatal, not majority). E023c's certificate identity = (envelope format/seed) + (tile key, rate/bit capacity) + user-bits digest; the port must define whether the metadata bit is inside the certified-user-bits digest (it is an LDPC user bit, so yes) and make completion's 'validate certified tile page/key/bit-length/symbol capacity → extract genuine fountain symbols' step strip the metadata bit before fountain-symbol extraction.
- COMPLETION ORACLE CAN GO IN-BAND: E023c needs an external manifest for the stop oracle (rank/symbol count never stop; only real decode + length + SHA-256). Holo v1's payload envelope is {sha256}{len}{data} — an in-band verified stop — so the manifest becomes optional/derivable, but every rule ports verbatim: real fountain-v2 decode, length check, SHA check, wrong-digest = fatal, fountain state NEVER feeds pilot/pose/payload/LDPC acquisition, and a score-style read-only outer audit (exit 0/2/3/4 contract) stays separate from acquisition.
- FOUNTAIN-INERT EDGE TILES MUST STAY A FIRST-CLASS DISTINCTION: legacy sheets have inert certificates (C3: 23; C2 single-capture: 75; two-capture: 85; confetti: 25) and one zero-capacity degenerate tile (0,51,34). Holo v1's per-printer geometry (slack → 4 borders) changes WHICH tiles are inert/degenerate, but the scorer/completion split between 'LDPC certificate' and 'fountain-bearing symbol' and the 'actual rank, not certificate count' rule must port.
