## 0. How to read this

**The rule (J1).** On the K decode path holo2 IMPLEMENTS `src/holo`'s receiver.
A difference is a DIVERGENCE TO FIX unless it is (a) holo2 doctrine the user
ruled — the pull model (hints are scheduling, priced tiers, no phases/barriers/
gates, event-driven wakes), tile-map authority + done-pixel projection, the
journal-authoritative store / commit wall, one-file/one-context — cited by name;
or (b) MEASURED equivalent, pinned. "Equivalent by argument" is **not** (b).
Where v1's mechanism has no home in the pull model, its EFFECT is reproduced
through wake + price, never dropped.

**Verdicts.** `DIVERGENT` · `ABSENT` (v1 has it, holo2 has nothing playing its
role) · `HOLO2-ONLY` (extra machinery that changes receiver arithmetic) ·
`EQUIVALENT-UNPINNED` (equivalent by argument only — the row names its pin) ·
`DOCTRINE-RULED-RECORDED` (ruled, but a real behavioural difference on the
corpus, kept on the ledger so it is not rediscovered). Rows the censuses
CLOSED as EQUIVALENT-MEASURED are not in the table except where a prior
document called them divergent — those carry the closure so nobody re-opens
them (rows 29, 30).

**RANK.** The row number IS the rank: 1 = largest expected yield on the two real
sheets + the scraps, ties broken by correctness risk. Rows 1–4 are measured in
tiles; 5–19 are expected; 20+ are correctness/audit/pins. (Rows 35b/35c/35d were
inserted by the completeness cross-check in §6 and are ranked with row 35, i.e.
no independent yield.) **59 rows, de-duplicated from 78 census entries.**
